# Included Tons

A small public directory for roll-off dumpster rental, starting in Austin, Texas.

The useful number is not the can size. It is how many tons are included before the landfill scale adds a line to the bill.

## For homeowners
Read the [Austin checklist](site/pages/austin-tx.html) and the [overage / scam notes](site/pages/overage-and-scams.html). Call the yard directly. This site does not book jobs and does not charge you.

## For local yards
A basic row on the Austin page is free if you send your own rates (size, included tons, overage per ton, extra-day fee, a phone a person answers). Email includedtons@proton.me with the word RATES.

## What this repository is
Static HTML in `site/`. That folder is what should be published. Everything under `drafts/` is internal and is not for the public site.
